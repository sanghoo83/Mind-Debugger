# Mind Debugger

피드백에서 사실과 감정을 분리하는 생각 파서. CBT 사고 기록지(thought record) 구조를 디버거 메타포로 옮긴 로컬 우선 웹앱.

한국어/영어 양국어 지원 — 헤더의 토글로 전환하며, 첫 방문 시 브라우저 언어를 따른다 (`src/i18n.jsx`).

**Core Questions** — 모든 디버깅은 5개 질문으로 환원된다:
1. 지금 내가 아는 사실은 무엇인가? → Step 1 캡처
2. 지금 내가 추가한 이야기는 무엇인가? → Step 2 추측
3. 증거 점수는 몇 점인가? (0~10) → Core Q3 슬라이더 (파서 추정 병기)
4. 내가 통제 가능한 것은 무엇인가? → Core Q4 입력
5. 지금 30분 투자할 가치가 있는 생각인가? → Step 5 + ⚠ WARNING

## 플로우

0. **저널** — 여과 없이 일기처럼 쓰면 파서가 문장 단위로 12개 시그니처를 다중 매칭(lint). 걸린 문장은 탭 한 번에 캡처 파이프라인으로 보내고, 저널은 감지 결과와 함께 보관.
1. **캡처 (Step 1)** — 해석 없이 사실만 빠르게 기록. 감정 강도(1–10)와 출처는 선택.
2. **파싱 (Step 2–3, 5)** — 감정이 식은 뒤 비동기로 분석:
   - Step 2: 사실에 섞인 추측을 적고 인지 왜곡 태그(독심술, 파국화, 개인화 등 10종) 부착
   - Step 2.5: 빠진 정보 — 추측이 아니라 확인으로 해소되는 것을 질문으로 기록, 원클릭으로 액션 변환
   - Step 3: 같은 사실을 설명하는 대안 해석 적기
   - Step 5: 액션 필요 여부 결정 (필요 없으면 "흘려보내기")
   - **파서 제안**: 캡처 텍스트를 10개 트리거 시그니처(`src/parser.js`)에 매칭해 흔한 함정·대안·확인 질문을 탭 한 번에 채택 가능하게 제안. 같은 패턴의 과거 기록 수·평균 강도·"별거 아니었음" 비율을 증거로 표시. 시그니처는 두 계열: 타인 메시지형 6종(작업물 필요성 질문, 재검토 요청, 칭찬+but, 보류 시그널, 개인 관찰, 모호한 단답) + 자기 대화형 4종(미래 확정 선고, 비교 모드, 자기비난 귀속, 항상/원래 확장)
   - **DEBUG REPORT**: 파싱 완료 시 감정 강도 vs 증거 품질(`10 − 대안×2 − 질문 − 왜곡`), 감지 왜곡, 반응 격차, 판정을 출력. 증거 ≤3 + 격차 ≥5이면 `⚠ WARNING: 지금 상상 속의 문제를 풀고 있습니다` 경고 발동
3. **24h 체크 (Step 4)** — 캡처 후 24시간이 지나면 "지금도 중요한가?"를 다시 묻고 답을 기록.
4. **대시보드** — 자주 걸리는 왜곡 패턴, 24시간 뒤 "별거 아니었음" 비율(내 데이터 기반 증거), 열린 액션. **데이터 섹션**: JSON 내보내기/가져오기, 빈 상태에서 예제 81건 원클릭 로드(`src/seed.js`에 번들).

> ⚠ localStorage는 브라우저 데이터 삭제 시 사라진다. 주기적으로 JSON 내보내기 권장.

## 실행

```bash
npm install
npm run dev   # http://localhost:5173
```

데이터는 브라우저 localStorage(`mind-debugger.entries.v1`)에만 저장된다. 서버 없음.

## 📱 폰에서 쓰기 (PWA 테스트 버전)

설치형 앱(Tauri APK)이 아니라 PWA로 폰에 올린다. 홈 화면에 추가하면 풀스크린·아이콘·오프라인으로 네이티브 앱처럼 동작하고, 데이터는 폰의 localStorage에 그대로 남는다.

**A. 가장 빠른 방법 — 같은 와이파이로 (HTTP, 오프라인 SW는 미동작)**
```bash
npm run dev:host          # 출력되는 Network 주소 확인 (예: http://192.168.0.12:5173)
```
폰(맥과 같은 와이파이)의 크롬에서 그 주소를 열고 → 메뉴 → "홈 화면에 추가". 서버가 켜져 있는 동안 바로 쓸 수 있다.

**B. 제대로 설치형으로 — HTTPS 정적 배포 (오프라인·자동 업데이트 동작)**
PWA 설치 프롬프트와 서비스워커는 HTTPS가 필요하다. 무료 호스팅에 `dist/`를 올리면 끝:
```bash
npm run build             # dist/ 생성 (sw.js·manifest 포함)
```
- 가장 간단: <https://app.netlify.com/drop> 에 `dist/` 폴더를 드래그 → HTTPS 주소 발급 → 폰 크롬에서 열고 "앱 설치".
- 또는 Vercel / Cloudflare Pages / GitHub Pages(이 경우 `vite.config.js`에 `base` 설정 필요).

> 앱 코드만 공개 호스팅될 뿐, 입력 데이터는 폰을 떠나지 않는다(클라이언트 전용 + localStorage).

아이콘 재생성: `npm run icons` (`scripts/gen-icons.mjs`, sharp로 `{ • }` 로고를 PNG로 굽는다).

## 구조

- `src/store.js` — 엔트리 데이터 모델, localStorage 영속화, 24h 재확인 판정
- `src/i18n.jsx` — ko/en 번역 사전과 로케일 컨텍스트
- `src/distortions.js` — 인지 왜곡 분류 체계 (로케일별 label/hint)
- `src/parser.js` — 룰 기반 제안 엔진: 트리거 시그니처 6종 + 과거 기록 통계
- `src/components/` — 탭별 뷰 (Capture / Parse / Recheck / Dashboard)
